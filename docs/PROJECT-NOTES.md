# Zero: что это, что сделано и что дальше

## Идея
Общие траты с друзьями, как в Splitwise, но проще и под телефон:
- внести трату: кто платил, как делим (поровну или точными суммами), потом по позициям чека;
- много людей, **без групп**: вместо групп необязательный тег («Грузия»);
- балансы по каждой валюте отдельно. Свести долг в одну валюту можно на выбранную дату по фиксированному курсу через доллар (курс запоминается в самом взаимозачёте и потом не меняется);
- история изменений «было → стало», удаление мягкое;
- голосовой ввод, ставится на экран iPhone и Android как приложение;
- вход **только через Telegram**; друзья по ссылке, QR-коду или нику в Telegram;
- «призрак»: человек без аккаунта («Саша»), к которому позже можно привязать настоящий аккаунт;
- в планах: подтверждение трат (необязательное), push, чеки с распознаванием через ИИ.

Возврат долга — не особый вид операции, а обычная трата: платил тот, кто отдаёт, доля целиком на получателе.

## Что уже работает
- Вход через Telegram (OpenID Connect с PKCE). Сессия живёт 60 дней. «Выйти» только откладывает сессию, повторный вход на этом устройстве проходит без Telegram.
- Друзья и траты на настоящей базе. У нового человека пустой экран с кнопкой «Добавить человека».
- Приглашение: личная ссылка и настоящий QR в шторке «Добавить человека». Открытая ссылка связывает двух людей в обе стороны, даже если человек сначала входит через Telegram.
- Добавление друга без аккаунта, порядок друзей перетаскиванием (ручной порядок побеждает, даже если баланс нулевой; пока ручного порядка нет, друзья с долгом выше).
- Трата: плательщик, доли, тег, валюта (50 штук, курсы пока демонстрационные), голосовая запись с автосохранением, правка и удаление, история изменений.
- «Вернуть долг» на странице друга, взаимозачёт валют, выбор валюты по умолчанию в настройках, смена аватарки по нажатию на неё, светлая/тёмная тема платформы (iOS или Android вид).
- Демо-режим без базы (кнопка «Войти в демо») для разработки.

## Следующие шаги (по порядку)
1. Привязка «призрака» к настоящему аккаунту по ссылке (в базе уже есть `invites.ghost_id` и `people.merged_into`, логики ещё нет).
2. Настоящие курсы валют по дням (таблица `exchange_rates` есть, заполнения нет).
3. Ввод траты без интернета (офлайн).
4. Голос: разбор фразы уже делает Claude Haiku на сервере (`lib/server/voice.ts`, маршрут `/api/voice`, ключ `ANTHROPIC_API_KEY` в `.env` на сервере; без ключа работают правила `lib/parse.ts`). Осталось распознавание речи на сервере: браузерное не работает в приложении на экране iPhone. Claude звук не принимает, нужен отдельный сервис (кандидаты: Groq Whisper с бесплатным тарифом, OpenAI).
5. Подтверждения трат, push-уведомления.
6. Резервные копии базы забирать ещё и на ноутбук (сейчас дампы только на сервере, 14 дней).

## Открытые вопросы дизайна (не делать без согласования)
- **История на главном экране.** Неясно, нужна ли. Довод «за»: после добавления траты непонятно, что она записалась. Сейчас это решено анимацией баланса. Вариант: блок «Недавнее» с последними 2–3 событиями.
- **Стрелка в строке друга.** Тап по строке = новая трата (нравится). Стрелка открывает страницу друга с общей историей, но это неочевидно. Кнопка «+» на каждой строке отклонена.
- «Делим на»: автору кажется, что чего-то не хватает, вернуться после пробы на телефоне.

## Известные ограничения
- Распознавание речи на iPhone в установленном приложении не работает (работает в Chrome на Android) — решается серверным распознаванием.
- Подтверждение входа в приложении Telegram не возвращает человека в Safari: iOS не даёт веб-странице вытащить Safari на передний план, нужно вернуться вручную. Страница сама перепроверяет вход, когда человек возвращается во вкладку. В [документации Telegram](https://core.telegram.org/bots/telegram-login) для обычного сайта способа вернуть человека в браузер нет, возврат описан только для нативных SDK (точное поведение на телефоне документация не расписывает).
- Без ключа Claude на сервере название, предложенное голосом, может выйти странным («Баре»): тогда фразу разбирают правила.
- Возможное расхождение: вход в установленном приложении на экране iPhone может не делить куки с Safari. Не проверено.
- В `app/api/me/route.ts` есть временный диагностический лог о причинах 401: удалить, когда пропадёт нужда.

## Решения, которые уже приняты
- Репозиторий публичный: в нём нет секретов, адреса сервера и домена. Всё серверное — в `deploy/local.env` и в `.env` на сервере.
- Telegram-вход делает сервер: Client Secret никогда не попадает в браузер.
- Деньги — целые числа в минимальных единицах.
- Группы не нужны, вместо них теги.
- Согласия на трату не обязательны: траты вносятся сразу с пометкой.
